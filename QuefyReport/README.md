# Quefy 月度作业报告

独立于 Attendance 的 Python 3.10+ 项目，无第三方依赖。在实际工作电脑（Windows）运行：

```powershell
py -3 QuefyReport/report.py
```

默认读取项目上一层的原始9月模板，生成当前月份报告到 `QuefyReport/output/`。模板必须保留原文件名。可用 `--template 路径`、`--output-dir 目录` 指定位置。重复运行生成新文件，不覆盖模板、参考完成版或之前的报告。

## 填写规则

- 使用 Windows 本地日期和时间，处理当月1日至运行时刻，包含周末和节假日。
- 出社取不早于07:00的最早开机/唤醒；退社取不晚于23:30的最晚关机/睡眠。阈值包含端点，比较精确到秒，表中写入小时和分钟。
- 运行当天的退社时间始终留空，即使已有关闭或睡眠记录；之后在同月重新运行时补填此前日期的退社时间。
- 无有效记录保持空白，不自动填写欠勤。有单侧记录时只填写该侧；退社早于出社时留空退社，避免错误工时。
- 有有效记录时填写 `出勤（Bosch）`、`ETCとVICS開発`。
- 自动修改年、月；原有公式计算整月日期、星期、15分钟取整、分段工时、出勤天数及汇总。请使用 Excel 打开生成文件以完成公式重算；不计算公式的预览器可能显示空白。
- 按“每天都包含”的规则，`稼働日`填当月日历天数。模板固定的基准160小时、下限140小时、上限180小时保持原样。
- 原始模板不写入。输出仅修改年月、日数、考勤输入及公式重算设置/缓存；保留格式、合并、图片、打印设置和公式。

## 数据来源

使用 PowerShell Get-WinEvent 读取 System 日志，同时检查事件来源与编号：Kernel-General 12/13（开机/关机）、Power-Troubleshooter 1（使用事件内 WakeTime 唤醒时间）、Kernel-Power 42（睡眠）。不把锁屏作为离岗，不使用6008事件的登记时间冒充断电时间。

日志被清理、异常断电、某些设备未记录睡眠等情况可能缺少记录，缺失时间保持空白。读取失败会报错；当天退社时间一律不填写，可在同月的后续日期重新生成补填。

离线输入可使用 `--events events.json`（仍只处理当前月），格式如下；无时区的时间视作本机时间，有时区的时间转换为本机时间：

```json
[
  {"kind": "startup", "timestamp": "2026-10-01T08:45:00"},
  {"kind": "shutdown", "timestamp": "2026-10-01T19:10:00"}
]
```

运行验证：`python -m unittest discover -s QuefyReport -v`。
